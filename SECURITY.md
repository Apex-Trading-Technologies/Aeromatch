# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting Security Issues

Apex Trading Technologies is committed to maintaining the safety and integrity of the AeroMatch engine. If you discover a potential vulnerability, please report it responsibly so our team can address it promptly.

### Disclosure Process

1. **Private Report**: Send details of the vulnerability to `security@apex-trading.tech`.
2. **Details to Include**:
   - Description of the attack vector or potential risk.
   - Minimal reproduction code or proof-of-concept steps.
   - Affected version(s) and operating system environment.
3. **Acknowledgment & Fix**:
   - Our security team will acknowledge your report within 48 hours.
   - We will provide status updates as we develop and verify remediation patches.
   - We request that you adhere to responsible disclosure guidelines and refrain from public disclosure until a patch is published.

Thank you for helping keep the open-source trading community secure.
